# Support

Most answers are in the documentation at [telmoni.com/docs](https://telmoni.com/docs): self-hosting, the console, the CLI, the SDKs and the Claude Code and Antigravity plugins, and the API, with what each [error](https://telmoni.com/docs/errors) means. If it does not cover what you need:

- **A bug or a feature request:** open an issue in the repository concerned: [`telmoni/telmoni`](https://github.com/telmoni/telmoni/issues) for the server, the console, the SDKs, the documentation and self-hosting, which live there; [`telmoni/telmoni-cli`](https://github.com/telmoni/telmoni-cli/issues) for the CLI; and each coding-agent plugin has a repository of its own: [`telmoni/claude-code-observability-plugin`](https://github.com/telmoni/claude-code-observability-plugin/issues) for Claude Code and [`telmoni/antigravity-observability-plugin`](https://github.com/telmoni/antigravity-observability-plugin/issues) for Antigravity.
- **A question the documentation does not answer:** open an issue on [`telmoni/telmoni`](https://github.com/telmoni/telmoni/issues), whatever part of Telmoni it is about.
- **Your account or an organization on telmoni.com:** write to hello@telmoni.com, and keep account details out of public issues.
- **A self-hosted deployment:** whoever runs it is your contact for accounts and access. Its console's footer and its emails give their address if they set one.
- **A suspected vulnerability:** never in public. Follow the [security policy](https://telmoni.com/docs/legal/security#reporting-a-vulnerability).
