# Support

Each repository's README and `ARCHITECTURE.md` are its documentation: start with [`telmoni/telmoni`](https://github.com/telmoni/telmoni) for self-hosting, the console, the SDKs and the API. If they do not cover what you need:

- **A bug or a feature request:** open an issue in the repository concerned: [`telmoni/telmoni`](https://github.com/telmoni/telmoni/issues) for the server, the console, the SDKs, the documentation and self-hosting; [`telmoni/telmoni-cli`](https://github.com/telmoni/telmoni-cli/issues) for the CLI; and the plugin's own repository for [Claude Code](https://github.com/telmoni/claude-code-observability-plugin/issues), [Codex](https://github.com/telmoni/codex-observability-plugin/issues) or [Antigravity](https://github.com/telmoni/antigravity-observability-plugin/issues).
- **A question the documentation does not answer:** open an issue on [`telmoni/telmoni`](https://github.com/telmoni/telmoni/issues), whatever part of Telmoni it is about.
- **A self-hosted deployment:** whoever runs it is your contact for accounts and access.
- **A suspected vulnerability:** never in public. Follow the [security policy](https://github.com/telmoni/.github/blob/main/SECURITY.md).
