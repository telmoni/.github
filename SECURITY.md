# Security Policy

Please do not report a vulnerability in a public issue, pull request or discussion.

## Reporting a vulnerability

Report it privately through the **Security** tab of the repository concerned: **Report a vulnerability**. If that is not available, write to hello@telmoni.com.

Include what is affected (the repository, and the version or commit), how to reproduce it, and what an attacker could do with it. You will get an answer, and credit in the advisory if you want it once a fix is out.

## Supported versions

Telmoni has no stable release yet: fixes land on each repository's `main` branch, and only `main` is supported.
